# Pace 预算规则（v1）

本文档冻结 Pace 第一版的预算计算规则。`shared/budget` 是本规则的唯一实现，Android 与 iOS 均通过共享核心调用，禁止在任何客户端单独实现预算计算。

## 1. 固定每日预算

第一版只提供固定每日预算模式：

> 今日剩余 = 今日预算 − 今日计入预算的净支出

- **今日预算**：生效日期不晚于今天的最近一条预算规则（见第 4 节）。
- **今日计入预算的净支出** = `Σ(计入预算的支出) − Σ(计入预算的退款)`（见第 2 节）。
- 结果为负数时展示为「超支」，绝对值即超支金额；不出现负号金额。

## 2. 计入规则

| 账单类型 | 是否计入每日预算 |
| --- | --- |
| EXPENSE 支出 | `countInBudget = true` 时计入 |
| REFUND 退款 | `countInBudget = true` 时按负数冲减当日净支出 |
| INCOME 收入 | 不计入 |
| TRANSFER 转账 | 不计入 |

- 每笔支出、退款可单独设置 `countInBudget`；收入与转账的该字段恒为 `false`，由共享核心强制归一。
- 不计入每日预算的支出仍然计入「全部支出」统计（见第 5 节）。
- 退款以其**自己的归属日**（`localDate`）冲减当日净支出，不回溯到原账单日期。

## 3. 结转规则

- 当日结余**不结转**到下一天：每天预算独立计算。
- 当日超支**不自动扣减**明日预算。
- 首页必须同时展示：预算、已花（净支出）、剩余或超支，以及一句计算说明文案：
  `今日剩余 = 预算 {budget} − 已花 {spent}`。

## 4. 预算规则与生效日期

- 预算规则字段：`id`、`dailyAmountMinor`（最小货币单位的 `Long`）、`currency`、`effectiveFromLocalDate`、`createdAtEpochMillis`。
- 某日的预算 = `effectiveFromLocalDate <= 该日` 的所有规则中 `effectiveFromLocalDate` 最大的一条；同日多条取 `createdAtEpochMillis` 最新一条。
- 修改预算 = 追加一条新规则（`effectiveFromLocalDate` 默认为当天），**不重写、不删除**历史规则。
- 某日早于所有规则的生效日时，该日预算为 `0`，并展示「该日期未设置预算」。
- `dailyAmountMinor` 必须满足 `0 <= 值 <= 10^13`（约 1 亿元，单位分）。

## 5. 统计口径

统计数字全部由本地确定性程序计算，与 AI 无关。

- **预算内支出（netSpend）**：当日 `countInBudget = true` 的支出 − 退款，即预算引擎使用的口径。
- **全部支出（totalSpend）**：当日所有 EXPENSE（不论 `countInBudget`），不减退款、不包含转账。
- **本周/本月支出**：以用户时区按 `localDate` 归组；本周 = 以周一为一周开始；本月 = 自然月。
- **分类排行**：按全部支出口径（totalSpend）统计 EXPENSE；REFUND 不参与分类排行。
- **超支记录**：`netSpend(date) > budget(date)` 且 `budget(date) > 0` 的日期列表。
- 预算对比图：区间内每日 `netSpend(date)` 与 `budget(date)`。

## 6. 引擎约束

- 预算引擎不依赖网络、AI 和系统语言。
- 输入统一为最小货币单位 `Long`，全程整数运算，禁止 `Double` 参与计算。
- 引擎是纯函数：同一组（账单集合、预算规则、日期、时区）输入在任何平台必须得到相同输出。
- 动态周期预算（`周期剩余预算 / 周期剩余天数`）属于后续版本，作为独立模式提供，不得与固定预算混算。

## 7. 验收案例

以下案例同时固化在 `shared/src/commonTest` 中，两端共享同一结果。

| # | 场景 | 输入要点 | 期望结果 |
| --- | --- | --- | --- |
| B1 | 普通日内 | 预算 5000 分，支出 1200 分 ×1 | 剩余 3800 分 |
| B2 | 退款冲减 | 预算 5000，支出 1200 + 退款 200（同日） | 已花 1000，剩余 4000 |
| B3 | 不计入预算 | 预算 5000，支出 1200（不计入）+ 800（计入） | 剩余 4200；全部支出仍为 2000 |
| B4 | 超支 | 预算 5000，支出 7000 | 剩余 -2000 → 展示「超支 2000」 |
| B5 | 结余不结转 | 10-01 结余 1000，10-02 无支出 | 10-02 剩余 = 10-02 预算 |
| B6 | 超支不传染 | 10-01 超支 2000，10-02 预算 5000 | 10-02 剩余 5000 |
| B7 | 生效日期 | 规则 A 自 10-01 为 5000，规则 B 自 10-10 为 6000 | 10-05 预算 5000，10-12 预算 6000 |
| B8 | 未设预算 | 无任何规则 | 预算 0，展示「未设置预算」，剩余不展示 |
| B9 | 收入/转账不计入 | 收入 100000、转账 3000、支出 1000 | 已花 1000 |
| B10 | 退款归属日 | 支出在 10-01，退款在 10-03（均计入） | 10-01 已花不变，10-03 净支出为负冲减 |
