# 草稿缺「类型」怎么补

P0 第 6 条：`DraftReviewView` 里类型从不显示、也没地方改，`missingFields` 一旦带上 `TYPE`，保存按钮永久禁用，页面就成了死路。

修法不是加一整行，是把类型做成卡片上本来就该有的那个小胶囊——`QuickAddView` 的草稿卡右上角已经这么画了，两处长成一样，用户认一次就够。

---

## 1. 位置

`DraftReviewView` 卡片第一行，现在是「标题 … 金额」。改成：

```
标题                [支出]  ¥28.00
```

- 胶囊在金额左边，间距 8，与金额**基线上对齐**（不是垂直居中，金额是 16 semibold rounded，胶囊是 11，居中会飘）。
- 金额为 0 时右边是「—」，胶囊同样在它左边。

## 2. 两种长相

和 `QuickAddView.swift:230-235` 那一颗同一套值，别再造一套：

| 状态 | 底 | 边 | 字 |
| --- | --- | --- | --- |
| 有类型 | `card2` 填充 | 无 | 11 medium `ink2`，内容 8/3 内距，Capsule(continuous) |
| 缺类型 | `card` 填充 | 0.5pt `accent` | 11 medium `accent`，字样「选类型」 |

缺类型用 accent 边框而不用灰：这一格此刻**是**要做的动作，不是一句说明。边框 0.5 与卡片描边同粗，不会显得比卡片更重。

## 3. 交互

胶囊本身是个 `Menu`。

- 两项，顺序固定：**支出 / 收入**。当前项打勾。
- 选中 → `draft.type = 值`，并从 `missingFields` 里去掉 `TYPE`。不改动其它缺失项。
- 这是唯一的补类型入口：不用 push 回编辑页，也不用先点「改」。
- 点击区：胶囊视觉尺寸不变，用 `.contentShape` 把命中区抬到 44 高（上下各补 10 左右的透明边距），否则 11pt 的胶囊按起来很难。
- 底部「先补类型」这类按钮保持现在的行为（只是解开禁用），不要让它自动滚动或高亮，滚动定位这轮不做。

## 4. 为什么菜单里没有「转账」「退款」

这两个不是能盲选的类型：转账要指定进出账户，退款要挑原支出账单。从一个只有两项的菜单里选出来，等于造一笔没有关联的错账。

所以：**菜单永远只有支出、收入两项。** 若草稿本来就是 `TRANSFER` / `REFUND`（模型回的、或从编辑页带进来的），胶囊照原样显示那个词，也照样能点开，但只能在支出/收入之间改——可以从特殊类型改回普通类型，永远不能从这里「无中生有」造一个特殊类型。

## 5. 明确不改的地方

- **编辑区（「改」之后）不加类型行。** 一个字段两个控件，迟早两处状态不同步。胶囊在卡片头部，编辑态也在，够用。
- **不 push 回 `AddView`。** 缺一个字段就换页面，比缺字段本身更烦。
- **缺类型时不禁用「改」「删除」。** 缺东西不等于这行不能处置。
- **重复检测、保存路径一律不动。**

## 6. 无障碍

- 胶囊：`.accessibilityLabel("类型")`，`.accessibilityValue(当前值或「没选」)`，`.accessibilityHint("点按选择支出或收入")`。选完朗读新值（「已改为收入」）。
- 菜单项用普通 `Button`，系统自带读出与触感。
- 11pt 的字不是障碍，但命中区必须是 44；这一条和上面第 3 节是同一个改动。

## 7. 验收（三个 case，缺一不可）

1. 草稿缺类型：胶囊是 accent 边框的「选类型」 → 点开选「收入」 → 底部按钮从「先补类型」变成「保存 1 笔」 → 保存后库里那一笔是 `INCOME`。
2. 草稿本来有类型：胶囊显示「支出」 → 点开选「收入」 → 胶囊变「收入」，其它字段一个不变。**这条不要求金额改色**：卡片里金额一直是 `ink`，别为了这个 case 新加一条着色规则。
3. 草稿带 `REFUND`：胶囊显示「退款」，菜单里只有两项，选「支出」能改过去；不能把一笔普通草稿改成退款。
