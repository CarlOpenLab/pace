# 控件材质与亮／暗色取值

这一版把两件事一次说清：每个控件是玻璃还是实底，以及它在亮色和暗色下分别是什么值。所有值都写死，不留「系统兜底」。

---

## 1. 材质只分三层

| 层 | 谁用 | 为什么 |
| --- | --- | --- |
| **玻璃**（系统材料） | 工具栏项（关闭、保存）、浮起来的按钮（记一笔）、卡片和列表上的次级按钮（改一下、删除、再试一次、取消） | 玻璃的职责是「浮在内容上的一层操作」；用系统那套，一颗玻璃和另一颗玻璃相邻时它们属于同一个视觉层，不会互相压。 |
| **实底**（`accent` / `onAccent`） | 一屏只有一个：真正提交的那个动作——草稿卡上的「记上」、设置里的「保存预算」、手动记一笔的「保存」 | 实底是「按下去会发生事」的信号。屏幕上超过一个，它就退化成装饰。 |
| **无色块** | 类型／分类／例句胶囊、状态胶囊、输入框 | 这些画的是**状态**不是按钮。选中态一旦变玻璃，就再也看不出选没选。 |

不要第四层。不要「玻璃 + 自己画的胶囊」叠着——之前那颗双层的保存就是这么来的。

## 2. 表

`ink2` 等符号见 `PaceStyle.swift`。括号里是实测对比度（对各自的底）。

### 2.1 工具栏

| 控件 | 材质 | 亮色 | 暗色 |
| --- | --- | --- | --- |
| 关闭（×） | 系统玻璃，**不要再关** `sharedBackgroundVisibility` | 图标 `ink` #0E0E0F | 图标 `ink` #F5F5F7 |
| 保存 | 系统玻璃 + 文字「保存」（16 semibold，`lineLimit(1)`） | 字 `ink` #0E0E0F | 字 `ink` #F5F5F7 |
| 保存·不可用 | 系统玻璃，**字色显式给** `ink2`（不吃系统调暗：暗色下玻璃上的字会被压到 2.18:1） | 字 `ink2` #6E6E73（5.84:1） | 字 `ink2` #A6A6AD（5.84:1） |
| 悬停/按下 | 系统处理 | — | — |

两颗都在同一个工具栏容器里，系统自己会算宽度和间距；不要再加 `.fixedSize()` 之外的自画尺寸，也不要再画胶囊。

### 2.2 页面里的按钮

| 控件 | 材质 | 亮色 | 暗色 | 不可用 |
| --- | --- | --- | --- | --- |
| 记一笔（浮起） | 玻璃 | 图标 `ink` / 底为材料 | 同左 | — |
| 主提交（记上／保存预算） | 实底 | 底 `accent` #1C1C1E，字 `onAccent` #FFFFFF（17.5:1） | 底 `accent` #F2F2F4，字 `onAccent` #0C0C0D（17.5:1） | 底 `card2` #F2F2F4 / #26262A，字 `ink2` #6E6E73 / #A6A6AD（4.5 / 6.2:1） |
| 次级（改一下、再试一次、取消） | 玻璃 | 字 `ink` | 字 `ink` | 字 `ink3` |
| 删除（文字按钮） | 玻璃 | 字 `danger` #C0392B（5.1:1） | 字 `danger` #FF8578（8.3:1） | 字 `ink3` |
| 滑动删除 | 实底红 | 底 `dangerFill` #C0392B，字白（5.4:1） | 底 `dangerFill` #C0392B，字白（5.4:1） | — |

**`dangerFill` 两色都是 #C0392B**：红是含义，不是明暗倾向，不许跟着主题翻成浅色。`danger`（#FF8578）只用于文字和图标。

### 2.3 状态与输入

| 控件 | 亮色 | 暗色 |
| --- | --- | --- |
| 类型/分类胶囊·选中 | 底 `accent` #1C1C1E，字 `onAccent` | 底 `accent` #F2F2F4，字 `onAccent` |
| 类型/分类胶囊·未选 | 底 `card2` #F2F2F4，字 `ink` | 底 `card2` #242426，字 `ink` |
| 例句胶囊 | 底 `card2`，字 `ink` | 底 `card2`，字 `ink` |
| 状态胶囊（在预算内／超支） | 底 `softFill`，字 `ink`／`danger` | 底 `softFill`，字 `ink`／`danger` |
| 输入框文字 | `ink` | `ink` |
| 输入框占位 | `ink2` #6E6E73（**改**：原 `ink3`，3.0:1 太浅） | `ink2` #A6A6AD |
| 卡片描边 | `line` 黑 10% | `line` 白 10% |
| 卡片内分隔线 | `line` | 白 12% #3D3D40（白 10% 在 `card` 上只有 1.53:1，暗色下几乎看不见） |
| 主按钮按下的反馈 | 透明度 0.85 + 缩放 0.97 | 同左 |

### 2.4 玻璃在有卡片时的那圈边（2026-10-26 实测）

亮色白卡上玻璃没有可折射的东西，整颗只剩一圈边。量到：胶囊内 252,252,252、卡片 255（1.03），边色 211–215、对卡片 **1.35:1**、宽 0.5–0.7 点。

- 规则：**边对卡片 1.3–1.5，宽 ≤0.7 点**。低于 1.3 看不见，按钮退化成两段文字；高于 1.5 开始像描边，而同一页没有第二个带描边的元素，它会显得比卡片重。
- 这圈边是系统玻璃画的，**不要另加一层描边**——加了就是两层边，正是之前那个毛病。只在系统不画边（白卡上整颗消失）时兜底：0.5 点、黑 12%（≈#E3E3E3）。不许拿 `ink3` 去描。
- 暗色实测 56,55,59 对卡片 26,26,28 = 1.47，比亮色的 1.35 略强，同一档。两个底色下不抹平——同一个材料自己会给出相近的分量。
- 玻璃按钮离卡片边 ≥12 点：贴着边的玻璃读起来像卡片缺了一块。

## 3. 暗色下现在是坏的，逐条给值

### 3.1 滑动删除是白底白字

原因不是滑动那行，是全局 tint：`PaceApp.swift:105` 把整个 App 的 tint 设成 `PaceColor.ink`，暗色下 `ink` 是 #F5F5F7，系统把滑动动作的底取成了它。

- 修：`BillsView.swift:336` 那颗 `Button(role: .destructive)` 上显式加 `.tint(PaceColor.dangerFill)`。
- 规矩：全局 tint 继续是 `ink`（开关、光标、链接都靠它），但**任何 destructive 控件必须显式给 tint**，不许吃全局；以后新加一处就在代码里写一行注释说明。
- 新值：`PaceColor.dangerFill = #C0392B`（亮暗同一值），字白。

### 3.2 不可用态在亮色下反而更低

现在的组合：`ink3` 字压 `card2` 底。

| | 亮 | 暗 |
| --- | --- | --- |
| 现值 | 2.92:1 | 3.63:1 |
| 改成 `ink2` + `card2`(#26262A 暗) | 4.54:1 | 6.23:1 |

改法：不可用的实底按钮，**底 `card2`、字 `ink2`**，别用 `ink3`。暗色 `card2` 从 #242426 微调到 #26262A，让字更立得住。

### 3.3 输入框占位太浅

`ink3` 在亮色卡片上只有 3.0:1。改 `ink2`（亮 4.7:1、暗 7.2:1）。占位字是用户读的唯一线索，不能比说明文字还弱。

### 3.4 列表分隔线在暗色卡片里消失

白 10% 压在 `card` #1A1A1C 上等于 #2E2E30，1.53:1。卡片内分隔线改白 12% #3D3D40。

## 4. 验收（可量）

1. 暗色下截图，滑动删除那颗：底是红、字是白，红值落在 #C0392B ± 6；不是白底。
2. 同一页亮色一张、暗色一张，逐个按钮对照 §2 的表；有系统玻璃的地方，玻璃外 2 点那圈像素跟画布差 ≤2（自画胶囊会差到 6 以上）。
3. 不可用态：取按钮底和字的两个像素算对比度，亮色 ≥4.5、暗色 ≥4.5。
4. 工具栏：一颗玻璃保存 + 一颗玻璃关闭，两颗之间没有第二层底，文字不是省略号。
5. 全屏数一遍实底：一屏最多一处（记上／保存预算）。
