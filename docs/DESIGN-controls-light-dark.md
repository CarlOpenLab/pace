# 控件材质与亮／暗色取值

这一版把两件事一次说清：每个控件是玻璃还是实底，以及它在亮色和暗色下分别是什么值。所有值都写死，不留「系统兜底」。

---

## 1. 材质只分三层

| 层 | 谁用 | 为什么 |
| --- | --- | --- |
| **玻璃**（系统材料） | 工具栏项（关闭、保存）、浮起来的按钮（记一笔）、页顶的两段切换（一句话／手动，2026-10-26 Carl 定）、卡片和列表上的次级按钮（改一下、删除、再试一次、取消） | 玻璃的职责是「浮在内容上的一层操作」；用系统那套，一颗玻璃和另一颗玻璃相邻时它们属于同一个视觉层，不会互相压。 |
| **实底**（`accent` / `onAccent`） | 一屏只有一个：真正提交的那个动作——草稿卡上的「记上」、设置里的「保存预算」、手动记一笔的「保存」 | 实底是「按下去会发生事」的信号。屏幕上超过一个，它就退化成装饰。 |
| **无色块** | 类型／分类／例句胶囊、状态胶囊、输入框 | 这些画的是**状态**不是按钮。选中态一旦变玻璃，就再也看不出选没选。 |

不要第四层。不要「玻璃 + 自己画的胶囊」叠着——之前那颗双层的保存就是这么来的。

| 滑动删除 | 实底红 | 底 `dangerFill` #C0392B，字白（5.4:1） | 底 `dangerFill` #C0392B，字白（5.4:1） | — |

### 2.3.1 页顶两段切换：槽换玻璃，选中段仍是实底

Carl 定：记一笔页顶「一句话／手动」也换成玻璃。落地只换**槽**，选中那一段不动：

| 件 | 值 |
| --- | --- |
| 槽 | 系统玻璃胶囊，高 44（内距 3，段高 38）；外面那 5+5 的点击区不变 |
| 选中段 | 实底胶囊：底 `accent`、字 `onAccent`（亮 17.01:1、暗 17.49:1），字 15 semibold |
| 未选段 | 字 `ink2`，无底无描边（亮 5.84:1、暗 8.08:1） |
| 段间 | 不加分隔线——选中段的实底已经把两块分开了 |
| 动效 | 选中块随手指 0.18 秒 ease-out 滑过去，不反弹、不加缩放 |
| 无障碍 | 两段各自是一个可点元素，带「已选中」状态；整条不合并成一个元素 |

为什么选中段不跟着变玻璃：两段都在玻璃上，选中就看不出来了。这一条和「状态胶囊不许变玻璃」是同一条规矩——玻璃表示「可以按」，实底表示「现在是这个」。

### 2.4 玻璃在有卡片时的那圈边（2026-10-26 实测）

亮色白卡上玻璃没有可折射的东西，整颗只剩一圈边。量到：胶囊内 252,252,252、卡片 255（1.03），边色 211–215、对卡片 **1.35:1**、宽 0.5–0.7 点。

- 规则：**边对卡片 1.3–1.5，宽 ≤0.7 点**。低于 1.3 看不见，按钮退化成两段文字；高于 1.5 开始像描边，而同一页没有第二个带描边的元素，它会显得比卡片重。
- 这圈边是系统玻璃画的，**不要另加一层描边**——加了就是两层边，正是之前那个毛病。只在系统不画边（白卡上整颗消失）时兜底：0.5 点、黑 12%（≈#E3E3E3）。不许拿 `ink3` 去描。
- 暗色实测 56,55,59 对卡片 26,26,28 = 1.47，比亮色的 1.35 略强，同一档。两个底色下不抹平——同一个材料自己会给出相近的分量。
- 玻璃按钮离卡片边 ≥12 点：贴着边的玻璃读起来像卡片缺了一块。

## 3. 暗色下现在是坏的，逐条给值

### 3.1 滑动删除是白底白字

原因不是滑动那行，是全局 tint：`PaceApp.swift:105` 把整个 App 的 tint 设成 `PaceColor.ink`，暗色下 `ink` 是 #F5F5F7，系统把滑动动作的底取成了它。

- 修：`BillsView.swift:336` 那颗 `Button(role: .destructive)` 上显式加 `.tint(PaceColor.dangerFill)`。
- 规矩：全局 tint 继续是 `ink`（开关、光标、链接都靠它），但**任何 destructive 控件必须显式给 tint**，不许吃全局；以后新加一处就在代码里写一行注释说明。
- 新值：`PaceColor.dangerFill = #C0392B`（亮暗同一值），字白。

### 3.2 不可用态在亮色下反而更低

现在的组合：`ink3` 字压 `card2` 底。

| | 亮 | 暗 |
| --- | --- | --- |
| 现值 | 2.92:1 | 3.63:1 |
| 改成 `ink2` + `card2`(#26262A 暗) | 4.54:1 | 6.23:1 |

改法：不可用的实底按钮，**底 `card2`、字 `ink2`**，别用 `ink3`。暗色 `card2` 从 #242426 微调到 #26262A，让字更立得住。

### 3.3 输入框占位太浅

`ink3` 在亮色卡片上只有 3.0:1。改 `ink2`（亮 4.7:1、暗 7.2:1）。占位字是用户读的唯一线索，不能比说明文字还弱。实测这颗原来是系统默认占位色，亮色只有 1.74，比 3.0 还浅——所以它不是「顺手调深一点」，是坏掉了。

### 3.4 列表分隔线在暗色卡片里消失

白 10% 压在 `card` #1A1A1C 上等于 #2E2E30，1.53:1。卡片内分隔线改 `lineStrong`：**暗色白 15%**，压在卡片上 = #3C3E3F，对卡面 1.61。

这条原来写的是「白 12%」，带着目标色 #3D3D40——两者对不上（12% 只到 #353537，1.39）。实现时按目标色取，是对的：**百分比是手段，色值是目的**，两个不一致时改的是文档，不是代码。亮色那条不变，仍是黑 10% #E6E6E6。

### 3.5 暗色下卡片和画布几乎一样（1.13:1，Carl：基本不可见）

实测：`card` #1A1A1C 对 `canvas` #0C0C0D = **1.13:1**。亮色下卡片靠阴影和差值 1.07 还能读出来，暗色下没有阴影，只剩这 1.13——卡片就是一整片黑。

改法：**填充不动，给卡片加一圈 0.5 点的边。**

| | 亮 | 暗 |
| --- | --- | --- |
| 卡片填充 | `card` #FFFFFF（不动） | `card` #1A1A1C（不动） |
| 卡片描边 | 保持现在的 `line` 黑 10% #E6E6E6（1.16，够用） | 新 `cardEdge` = 白 16% 叠在卡片上 → **#3F3F40**，对画布 **1.86:1**、对卡片 1.65 |
| 宽 | 0.5 | 0.5 |

为什么只改边不改填充：填充一抬，全 App 的层次都要跟着重算（`card2`、`softFill`、玻璃边上那圈 1.35–1.5 的规矩全得变）；边是局部量，0.5 点、一条线，改完不牵动别的。1.7–2.0 这个区间是「看得见但不抢」——和玻璃那圈边 1.3–1.5 是同一种判断，只是卡片是容器，它该比按钮重一点。

`line`（白 10%）继续管卡片**内部**的分隔线，别拿它当卡片描边——那对画布只有 1.67。

### 3.6 「计入每日预算」的开关在暗色下看不见（1.12:1）

实测：这颗开关 `.tint(PaceColor.accent)`，暗色 `accent` = #F2F2F4（近白），系统开关打开时的圆点是白色 → **圆点对轨道 1.12:1**，等于没有圆点，只剩一个白胶囊。亮色没问题（17.01:1）。

改法：**换掉系统开关，用自画勾选块**（Carl 说的「勾选组件」）。

| 件 | 值 |
| --- | --- |
| 块 | 22×22，圆角 7，居中在行的右侧 |
| 未选 | 无底，1.5 点描边 `ink3`（亮 #8E8E93 对白 3.26、暗 #7A7A80 对卡 4.07） |
| 已选 | 底 `accent`，勾 `onAccent` 13 semibold（亮 17.01、暗 17.49） |
| 整行 | 仍是可点的，命中高 ≥44——块小，目标不小 |
| 无障碍 | 按开关报：角色是开关、状态是「已打开／已关闭」，别报成普通按钮 |
| 动效 | 0.16 秒，只换底和勾，不加弹簧 |

关键的一条：**勾的像素不许和块底同色**。这条正是这次坏掉的原因——系统开关的圆点是白色，而我们给的轨道也是白色。以后任何「底 + 勾」的组合，都要拿这两个像素算一次，≥4.5 才算过。

### 3.7 钉住的玻璃条下面那道缝会切出半截字

最大档实测：切换器胶囊下沿和内容的裁切线之间还隔着约 12 点画布（切换器自己的 7 点下内距 + 5 点命中扩展都算进了 inset 高度），于是卡片被一条看不见的线拦腰切断，切线上正好半行字露在画布上——上半截没了，下半截落在灰底上。默认字号看不出来，因为行短、卡片底总能盖住。

主改法：**让裁切线和胶囊下沿相差 ≤2 点。** 底部那 5 点命中扩展不要占布局高度（用 `contentShape` 撑，不改 padding），7 点下内距收到 2。切线和玻璃贴住之后，人看到的是「一张卡从玻璃底下滑过去」，那是正常样子。

兜底：再叠一层**8 点渐隐**（自上而下 alpha 0→1），只在滚动偏移 >0 时出现——停在顶部时第一张卡不动它，别让静止的页面顶边发灰。

验收：切换器下沿到第一张卡之间那一条，截图里不许出现任何笔画；切线与胶囊下沿 ≤2 点；停在顶部时第一张卡顶边不被压暗。

### 3.8 勾选块在最大字号下的对齐

块本身保持 22（它是记号不是字，不跟字号长），但**要和第一行文字对齐**，不是整块居中：两行标题时居中会让块落在两行中间，看起来像挂在行缝里。对齐量：块的上边缘对齐第一行文字的字形顶（`VStack` 用 `.firstTextBaseline` 或 `.top` 对齐，视觉差 ≤3 点）。

## 4. 验收（可量）

1. 暗色下截图，滑动删除那颗：底是红、字是白，红值落在 #C0392B ± 6；不是白底。
2. 同一页亮色一张、暗色一张，逐个按钮对照 §2 的表；有系统玻璃的地方，玻璃外 2 点那圈像素跟画布差 ≤2（自画胶囊会差到 6 以上）。
3. 不可用态：取按钮底和字的两个像素算对比度，亮色 ≥4.5、暗色 ≥4.5。
4. 工具栏：一颗玻璃保存 + 一颗玻璃关闭，两颗之间没有第二层底，文字不是省略号。
5. 全屏数一遍实底：一屏最多一处（记上／保存预算）。切换器选中段是状态，不算这处。
6. 暗色卡片边：取画布、卡片、边三个像素，边对画布 1.7–2.0、宽 0.5 点；卡片填充和画布填充的差仍是 1.13（没被顺手一起改）。
7. 勾选块：已选态取勾和块底两个像素 ≥4.5；未选态取描边和卡片两个像素 ≥3.0。
8. 切换器：玻璃槽外 2 点那圈像素与画布差 ≤2（自画胶囊会差更多）；选中段字对底 ≥4.5；两段都 ≥44 高。
9. 接缝：切换器下沿到第一张卡之间不许有笔画（最大档最容易露）；切线与胶囊下沿 ≤2 点；停在顶部时第一张卡顶边不被压暗。
10. 勾选块：最大字号下块仍是 22（不跟字号长），但与第一行文字字形顶的差 ≤3 点；整行命中 ≥44。
