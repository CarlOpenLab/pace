# 一句话记账设置页：服务商预设 + 模型下拉（design 补充稿）

> 适用：设置 → 一句话记账（`QuickAddSettingsView.swift`）。
> 范围：**只改那张「三项」卡片内部**（`fieldsCard`），页面其它部分（开关卡、测试连接、结果行、安全提示卡、清空 Key、toast）不重排、不改样式。
> 依据：`docs/DESIGN.md` 的 token、字体、间距、状态与无障碍规则。不新增颜色、不新增卡片、不新增页面、不新增动画种类。
> 文案：所有可见文字最终由 Camo 定，本文件里的中文是**占位**，标了 `Copy.*` 键名，Pluso 先按占位实现。

## 1. 这一段的变化

改之前：接口地址 / 模型名 / Key 三行，全部手填。

改之后：服务商 → 接口地址（预置点一下就填好，仍可改）→ Key → 模型（列表里选，拉不到就手填）。

```
┌─ fieldsCard（不变：card 底 / 26 圆角 / 16 内边距 / 0.5pt line 描边）──────┐
│ 服务商                                  （字段标签 15 ink，另起一行）      │
│ [DeepSeek] [OpenAI] [OpenRouter] [自定义]   ← 胶囊，可横向滚动            │
│ ─────────────────────────────── 1pt line ─────────────────────────────  │
│ 接口地址                                                               │
│ https://api.deepseek.com/v1/chat/completions          （15，占满一行）   │
│ 按 OpenAI 兼容格式填。…                        （11 ink2，现有说明不动）  │
│ ─────────────────────────────── 1pt line ─────────────────────────────  │
│ Key                                    sk-••••••  [清空 Key]            │
│ 只存在这台手机的钥匙串里…                        （11 ink2，现有说明不动） │
│ ─────────────────────────────── 1pt line ─────────────────────────────  │
│ 模型名                              deepseek-chat  ⌄    ← 下拉行         │
│ 状态行（只在加载中 / 失败时出现，最多两行）                               │
│ ─────────────────────────────── 1pt line ─────────────────────────────  │
│ 没填这三项，就用本机规则整理…                    （11 ink2，现有说明不动） │
└──────────────────────────────────────────────────────────────────────┘
```

顺序的理由：服务商决定地址，地址 + Key 决定能拉到哪些模型，所以模型排在 Key 下面——用户填完 Key，下一行就出现可选模型，不用回头找。

## 2. 服务商：一排胶囊

| 项 | 规格 |
| --- | --- |
| 字段标签 | 「服务商」15 `ink`，单独一行，行下间距 8（用词按 Camo 定的：公司那一行叫「服务商」，「服务」只指用户填的那个服务） |
| 胶囊行 | `HStack(spacing: 8)` 包在横向 `ScrollView`（`.scrollIndicators(.hidden)`）里，左右不额外缩进（跟卡片内边距对齐） |
| 胶囊 | 复用 `PillChipStyle`：14 medium，左右 14 / 上下 7，最小高 44，胶囊；选中 `accent` 底 `onAccent` 字；未选 `card2` 底 `ink` 字；按下 0.8 |
| 选项 | DeepSeek / OpenAI / OpenRouter / 自定义（Camo 定显示名；以后加 Kimi、智谱直接往数组里加，行本来就滚） |
| 选中行为 | 点预置 = 把该服务商的**基址**写进接口地址（只写地址，不碰 Key、不碰已选模型），模型行回到「未拉取」状态并按新地址重新拉一次 |
| 自定义 | 点「自定义」保留当前地址文本，焦点移到地址输入框；**用户手动改地址且改到不属于任何预置时，选中项自动变回「自定义」**，不给提示、不弹 toast |

| 地址说明 | 那行 11 `ink2` 的说明（「按 OpenAI 兼容格式填…」）**只在「自定义」下出现**。选了预置时它是在重复胶囊已经说过的事 |

选中态只在胶囊上表达（实底黑），不加勾、不加小字。

## 3. 模型行：一行的五种状态

行高固定 **44**（`minHeight: 44`），保证状态切换时卡片不上下跳。

左边标签按状态换，用词按 Camo 定的：「下拉那行叫**模型**，手打的那个叫**模型名**，两个词不互换」——能选的时候标签是「模型」，手填的时候是「模型名」。都是 15 `ink`，版式完全一样。

| 状态 | 右侧显示 | 行可点？ | 行下状态行 |
| --- | --- | --- | --- |
| A 未就绪（地址或 Key 为空） | **就是输入框**（见 §5），里面是已保存的模型名 | — | 12 `ink2`：「先填地址和 Key，模型列表会自动出现。」 |
| B 加载中 | 当前模型名或「正在拉取…」15 `ink2` + `ProgressView().controlSize(.small)`（16） | 否 | 12 `ink2`：「正在拉这个账号的模型…」 |
| C 拉到了 | 当前模型名 15 `ink2` + `chevron.up.chevron.down` 11 semibold `ink3` | 是，弹出菜单 | 无（没选过时 12 `ink2`：「拉到了 N 个模型。」） |
| D1 Key 不对 / 没权限 | 保持原样，**去掉右下角箭头** | 否 | 12 **`danger`**：「Key 没通过，拉不到模型列表。」+ 右侧 13 medium「重试」 |
| D2 不支持列模型 | 保持原样，去掉箭头 | 否 | 12 `ink2` + 12 `info.circle`：「这个服务不提供模型列表，手动填。」不带重试 |
| D2 网络不通 | 保持原样，去掉箭头 | 否 | 12 `ink2` + `info.circle`：「连不上，检查一下网络。」+「重试」 |

细节：

- **失败态不换控件，只换说明。** 行里还是那个模型名，箭头去掉，下面一行说清为什么拉不到、怎么继续；能重试的给重试。行不会突然变成一个框——用户刚才看的东西不该凭空变形。
- **手填入口不在这里藏。** 它常驻在行下面一行（§5），从 C 开始一直可见，失败时它还在原地，用户不用去找。
- **值永远用 `ink2`，不用 `ink3`。** `ink3` 在卡片上只有 3.26:1（浅色），读不了；「还没选」也是要读的字。
- **只有 D1 用红。** Key 不对是用户要去处理的事；不支持列模型和断网不是用户的错，用中性 `ink2` + 信息图标——否则用户会以为自己做错了什么，而这恰好是可预期的情况。
- 状态行**只在需要时出现**，出现时淡入 0.15s；卡片高度增加一行（约 18pt），不做高度动画、不做位移动画。
- 状态行最多两行，超过截断成一行 + 省略号（实践上不会发生，服务商的错误说明不进状态行）。
- 同一时间只有一种状态行。
- 重试：13 medium，`ink`，`frame(minHeight: 44)`，右对齐，点一次重新拉列表，拉取中回到 B。
- **进页面就自动拉一次**：地址和 Key 都在时，页面出现（`.task`）直接进入 B，没有「读取模型」按钮要人先点；Key 或地址改完并失焦时再拉一次。只有失败之后才由用户点「重试」。
- **不替用户选模型**：拉回来的列表只在用户点选后才写入。模型名为空就一直是「还没选」，不做「默认取第一个」——几百个模型里第一个很可能是嵌入模型或已下线的，选错了就是每次记账都失败。

行下三层的顺序固定：**状态行（有才出现）→ 手填入口（常驻）→ 原来那句 11 `ink2` 的隐私说明**。这样手填入口的位置在任何状态下都不动。

## 4. 下拉菜单长什么样

用系统 `Menu`（和记一笔里的「账户」「原账单」同一套，不新建自定义弹层）。锚点在模型行上。

- 菜单项：可用模型，每项 15（系统菜单字号），当前选中的那项**带系统勾选**。
- 排序：当前已保存的模型如果也在列表里，排第一；其余按服务商返回的顺序（不重排、不猜测「哪个更好」）。
- 菜单项数量不设限；超过系统高度由系统自己滚动，我们不加分组、不加搜索框。
- **菜单里没有「手动填写…」这一项。** 手填入口常驻在行下面，菜单只负责从列表里选，一件事一个地方。
- 当前保存的模型**不在**返回列表里时（换过服务商、服务商下线了这个模型）：菜单第一项固定为当前值，带勾，右侧 11 `ink2` 的「当前」；不禁用、不清空、不提示错误。列表里其余项照常可选。
- 选择即保存（这一页没有保存按钮），菜单收起，行回到 C，状态行消失。
- 菜单本身不加图标、不加描述、不加价格或能力标签——服务商返回什么就显示什么。

### 4.1 列表很长的时候：换成带搜索的选择页

OpenRouter 一次能返回几百个模型，系统 `Menu` 里翻不到，靠滚是没法用的。所以按条数分两种选择面，**模型行本身长得一模一样**（值 + ⇅），用户不需要预先知道会弹哪一种：

| 返回条数 | 点模型行打开什么 |
| --- | --- |
| ≤ 15 | 系统 `Menu`（上面 §4 那套） |
| > 15 | 底部弹出「选择模型」页：搜索框常驻 + 列表 + 已选打勾 |

「选择模型」页：

- 系统 `.sheet`，`presentationDetents([.medium, .large])`，初始 `.large`（几百条要能一屏看多一些）。
- 标题行：左「取消」15 `ink2`，中间「选择模型」17 semibold `ink`，高度 44。取消在左（这是选择，不是新建）。
- 搜索框：`card2` 底，高 36，圆角 10，左侧 `magnifyingglass` 14 `ink3`，占位「搜索模型名」15 `ink3`，进页即聚焦、键盘弹出。搜索不区分大小写，匹配子串。
- 行：高 44，模型名 15 `ink` 左对齐、单行截断；已选那行右侧 `checkmark` 15 `ink`。行与行之间 0.5pt `line` 分隔（从第二行开始）。
- 不分组、不加「推荐」标签——我们不知道哪个模型对用户的一句话记账更好，标「推荐」是在替用户做决定，而猜错一次就是长期失败。
- 搜不到：居中两行，12 `ink2`「没有匹配的模型」+ 12 `ink2`「关掉这页，用行下面的『手填模型名』。」不给「搜索服务商」外链。
- 点一行：存下、关页、行回到 C，状态行消失。
- 深浅色：全部走 §6 的 token，没有新增色值。

首屏是否自动聚焦：进入即聚焦（用户点这个行就是为了选，多一次点击没有意义）。

## 5. 手填入口：常驻，不是失败才出现

**位置**：模型行正下方，左对齐，高度 28（`HStack`，不占额外间距，跟在状态行后面）。任何时候都在，包括加载中、拉到了、已存模型不在列表里。

- 文案「手填模型名」，13 medium，`ink2`；前面一个 10 `square.and.pencil`（`tint: ink2`），间距 4。
- 点击区用 `.contentShape(Rectangle())` + `.frame(minHeight: 44)` 向上下扩，视觉高度仍是 28，不撑高卡片。
- 只有一种情况不出现：A（地址或 Key 还没填、一次都没拉到过列表）——那时行本身就是输入框，再放一个「手填」是自相矛盾。
- 无障碍：`accessibilityLabel("手填模型名")`，`accessibilityHint("在这一行里直接输入服务商文档里的模型名")`。

**点下去**：同一行的控件换成输入框，标签从「模型」变「模型名」，位置和行高一模一样，不展开新行、不弹 sheet、不跳页。

- 输入框：右对齐，15 `ink`，`card2` 底胶囊（高 32，圆角 10，左右内距 10），占位是服务商文档里的短名字（如 `deepseek-chat`），`.autocorrectionDisabled()`、`.textInputAutocapitalization(.never)`，进入即聚焦。
- 回车或失焦即保存（这一页没有保存按钮）。
- 行下状态行换成 12 `ink2`：「从服务商文档里抄名字，写完自动保存。」
- 入口文案变成「改用列表」（`list.bullet` 10，13 medium，`ink2`），点了回到 C；**没拉到过列表就不出现这一项**，只留说明行。
- 手填的值不做格式校验：服务商的模型名没有统一规则，我们能验证的只有「拉列表时它是否在返回里」，而这个验证不该阻止用户先存下来。

## 7. 无障碍

- 每个服务商胶囊：label = 服务商名，选中项加 `.isSelected`；hint「会填好接口地址」。
- 模型行：`.accessibilityLabel("模型名")`，`.accessibilityValue(当前模型名或「还没选」)`，hint「点开选择模型」；加载中 value 换成「正在拉取」，并加 `.updatesFrequently`。
- 状态行：作为模型行的一部分朗读（`children: .combine` 到同一元素里），文字更新时用 live region 读一次；不要让它成为一个只有屏幕阅读器才发现的孤立元素。
- 手填输入框：label「模型名，手动填写」。
- 长列表选择页：标题「选择模型」，搜索框 label「搜索模型名」，每行 `accessibilityAddTraits(.isSelected)` 给已选那条；点行 = 按钮行为，不是列表选中态。
- 手填入口：label「手填模型名」，hint「在这一行里直接输入服务商文档里的模型名」；输入态变成「改用列表」。
- 重试按钮：label「重新拉取模型列表」，最小点击区 44。
- 胶囊与行的点击区都 ≥ 44（胶囊样式本身已保证）。

## 9. 给 Camo：手填入口是常驻的，不在失败时才冒出来

按 Ato 定稿：模型行下面常驻一个「手填模型名」，加载完、选好了、失败时都在同一个位置。失败态只换状态行的说明和颜色，不换控件、不弹新东西、不把人送到别处。

所以四句失败文案里「手填模型名也照样能用」这类兜底句可以删——控件就在眼前，不用说。需要保留提示的只有 A（地址或 Key 还没填）那一条，因为那时确实是空的。

## 10. 这块不做的事

- 不新增卡片、不新增页面、不重排设置页。
- 不做自定义下拉弹层（用系统 `Menu`）。
- 不在列表里加搜索、分组、「推荐」标记。
- 不缓存列表到磁盘（内存即可，按 Ato 的规格）。
- 不用绿色表示「拉取成功」——绿只表示钱进来；成功就是普通的静默。
- 不为这块新增任何动效，只有状态行淡入 0.15s。
