# 分段切换器：一个组件，三处用

记一笔（一句话 / 手动）、账单（本周 / 本月 / 全部）、统计（本周 / 本月）用的是同一个控件。这是规范正本；`DESIGN-add-mode-switch.md §1` 只留位置和叫法，指向这里。

## 0. 为什么不直接用系统那颗

系统的 `.pickerStyle(.segmented)` **不跟字号走**。最大档、同一台机器、同一屏（`BILLS-max.png`，3 倍图）：

| 位置 | 字形像素高 | 折成点 |
| --- | --- | --- |
| 「本周 / 本月 / 全部」那行 | 35 | ≈ 11.7 |
| 同屏「餐饮」 | 120 | ≈ 40 |

差 3.4 倍。所有正文都放大了，只有那颗停在默认字号。这是全 App 最后一处不跟用户字号走的字，换成系统控件就是把这一处留在三个页面上。

所以自己画，并且只有一份实现，三处都用它。

## 1. 长什么样（亮 / 暗）

参考就是系统那颗的长相，只把它换成活的：**玻璃槽 + 一块抬起来的胶囊**。

| 件 | 亮 | 暗 |
| --- | --- | --- |
| 槽 | `.glassEffect(.regular, in: .capsule)` + 槽内压 `black 6%` | 同结构，槽内压 `white 6%` |
| 槽在画布上的实际色 | ≈ #E8E8E8（画布 #F7F7F7） | ≈ #1B1B1C（画布 #0C0C0D） |
| 槽描边 | `black 12%`，0.5 点，贴内圈 | `white 12%`，0.5 点 |
| 选中块 | `card` #FFFFFF | 槽上叠 `white 22%` = #4D4D4E |
| 选中块投影 | `black 14%`，半径 1.5，下移 1 | 不用投影（见下） |
| 选中块描边 | 无 | `white 12%`，0.5 点，贴内圈 |
| 字 | `ink`（选不选中都是 `ink`） | `ink` |

**选中不靠换字色。** 系统那颗选中的字和没选中的字是同一个黑（实测两处最深处都是 0,0,0，对底分别是 21.0 和 17.0）。选中是那块胶囊「抬起来」告诉你的：比槽亮一档（白对 #E8E8E8 = 1.16:1）、加一道投影。所以：

- 字统一 `ink`，不跟随选中态变浅或变白——一旦用字色分胜负，选中块就只是装饰。
- 未选中**不用 `ink2`**：ink2 压在 #E8E8E8 上只有 4.08:1，15 点不算大字，过不了 4.5。ink 是 17:1。
- 选中态的无障碍身份由 `.isSelected` 给，不靠颜色。

**暗色下「抬起来」失效，得换一套线索。** 投影是黑的，压在 #1B1B1C 的槽上等于没有，暗色里唯一能用的就是亮度差和一根边：

- 选中块 = 槽上叠 `white 22%` → #4D4D4E，对槽 **2.04:1**。这是能过的下限，不再往上加——再亮就变成一块发光的块，抢走字。
- 再加 0.5 点 `white 12%` 描边（对块面 1.3:1）：形比亮度先被眼睛抓住，2.04 只负责「亮一档」。
- 不照搬系统的 #636366（对槽 2.87:1）：那是系统自己的一套灰阶，我们暗色的卡面是 #1A1A1C，用 2.87 会比卡片还亮，切换器变成页面上最亮的东西。

（Ato 给的 #48484C「约 2.2:1」实测是 **1.89:1**，不过 2:1 —— 照算式的下限取 #4D4D4E。）

**为什么槽不是纯玻璃。** 纯玻璃压在 #F7F7F7 画布上是 #F5F5F5 左右，白胶囊压上去 1.02:1，选中块会化掉。所以槽里压 6% 的墨——系统那颗的槽 #E7E7E8 对画布也就 1.13:1，一样的思路。压了这 6%，玻璃仍然在：内容滚到它底下时照旧模糊，只是静止时也有边界。

**描边是「这是一块玻璃」的唯一静态线索。** 白底上玻璃本身没有形；1.33:1 的一根 0.5 点线，是它看起来像一块板而不是一片浅灰的原因。

## 2. 尺寸与字号

| 件 | 值 |
| --- | --- |
| 槽高 | 44，按 1.6 倍封顶跟着字号长（默认档就是 44，最大档 70） |
| 槽内距 | 3 |
| 段高 | 槽高 − 6（默认 38） |
| 段宽 | 等宽平分，不按字数 |
| 容器内距 | 左右 20；上 8、下 12 |
| 字 | `paceFont(15, .semibold)`，单行，随字号 |
| 圆角 | 胶囊 |

**最大档不许有省略号，也不许缩字。** 装不下就整行横向滚动，跟分类胶囊一条规矩。本 App 的词都在三个字以内，最大档（1.6 倍，24 点）量下来：两个词 96 + 72 = 168 点，三个词约 216 点，可用宽度 322 点，都装得下，正常情况下不会触发滚动。真挤不下的词找 Camo 出短形式，**改词不改字号**。

## 3. 动

选中块移动用 `matchedGeometryEffect`，`easeOut 0.18`。不做缩放回弹，不做颜色渐变——胶囊是滑过去的，不是淡入的。

## 4. 状态

| 状态 | 表现 |
| --- | --- |
| 默认 | 见上 |
| 按下（未选中段） | 该段文字 `ink`，槽内不加任何高亮；抬起由系统点在 0.18 秒里滑过来 |
| 滚动内容经过 | 槽下模糊；不做额外渐隐，接缝规则见 `DESIGN-controls-light-dark.md` |
| 三处都只有一个 | 页面上永远只有一颗切换器；不叠第二颗 |

## 5. 无障碍

- 根本身：`.accessibilityElement(children: .contain)`，每个段是一个可点元素。
- 每段 label 就是词本身（「一句话」「手动」「本周」「本月」「全部」），不带「选中」两个字。
- 选中段带 `.isSelected`。
- 记一笔那颗整颗带 hint：「切换填法，已经填的内容不会丢」；账单、统计不带 hint——切换范围的结果是立刻看得见的数字变化，不需要预告。

## 6. 验收（照这个量）

1. 默认档：槽高 44、段高 38、胶囊与槽内距 3。
2. 最大档：段里的字高与同屏正文的比值 ≈ 15 / 17（不是系统的 35 / 120）。
3. 最大档：三个词的段都完整，无省略号、无缩字。
4. 亮色：槽 ≈ #E8E8E8，胶囊 #FFFFFF，投影可见，字对底 ≥ 4.5。
5. 暗色：槽 ≈ #1B1B1C，胶囊 #2C2C2E，投影可见，字对底 ≥ 4.5。
6. 选中的可辨识度：把截图转成灰度，胶囊边界仍然看得出（投影和亮度差都在，不是只靠颜色）。
